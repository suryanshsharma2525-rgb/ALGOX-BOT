Show the prompt
Write ONE Python file for a trading bot. Follow these rules EXACTLY.

FILE FORMAT
- Output only the complete code in a single code block, nothing else.
- The file must contain:
    NAME = "short strategy name"
    def signal(candles):
        ...
- Do NOT use any import at all (no numpy, pandas, talib, math). If you need
  an indicator (RSI, moving average, EMA, Bollinger, etc.), write it by hand
  with plain Python inside the file.
- No input(), print(), files, internet, random or time functions.

WHAT signal(candles) RECEIVES
- candles is a list of dictionaries, OLDEST first, NEWEST last (candles[-1] is the latest).
- Each candle has these keys: "open", "high", "low", "close", "time".
- Use only open, high, low and close. Do not use "time".
- The latest candle, candles[-1], is a COMPLETED candle.

WHAT signal(candles) MUST RETURN
- "call"  -> price will go UP
- "put"   -> price will go DOWN
- None    -> no trade
- Return exactly these values, nothing else.

SAFETY RULES
- First line of signal() must check there are enough candles
  (for example: if len(candles) < N: return None) where N is the most
  candles my rules need, plus a few extra.
- Never divide by zero. Return None if a calculation is not possible.
- Never crash: if something is missing, return None.

Marginal safety

The bot does not enter at the opening price. It waits for a better entry, then trades. Works for UP and DOWN signals.

Pick UP or DOWN, then pick how the candle closes.

The candle starts at the open line, its wick goes to the bot’s entry, and then it closes. Because the entry is better than the open, a strong candle, a doji or a small candle all end in profit in this example.
